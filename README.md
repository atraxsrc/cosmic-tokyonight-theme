## COSMIC Desktop

Settings → Desktop → Appearance → **Dark** → **Import** → `cosmic/TokyoNight.ron`

Or from a terminal in this folder, which takes the whole file:

```bash
cosmic-settings appearance import cosmic/TokyoNight.ron
```

Since the COSMIC builds after 1.11.0 the **Import** button keeps your current
frosted glass (level, on/off per surface, opacity), gaps and active hint, and
takes only the colours, corners, fonts and icons from the file. The terminal
command applies this rice's frosted glass too, and so does `themebox flip`.

The whole palette is Tokyo Night, in the same format as the DarkGold baseline:
background ![#1A1B26](https://placehold.co/12x12/1a1b26/1a1b26.png) `#1A1B26`, containers ![#24283B](https://placehold.co/12x12/24283b/24283b.png) `#24283B` / ![#292E42](https://placehold.co/12x12/292e42/292e42.png) `#292E42`, navy neutrals from
![#3B4261](https://placehold.co/12x12/3b4261/3b4261.png) `#3B4261` to ![#C0CAF5](https://placehold.co/12x12/c0caf5/c0caf5.png) `#C0CAF5` (so frosted glass tints navy, not grey), accent blue
![#7AA2F7](https://placehold.co/12x12/7aa2f7/7aa2f7.png) `#7AA2F7`, success ![#9ECE6A](https://placehold.co/12x12/9ece6a/9ece6a.png) `#9ECE6A`, warning ![#E0AF68](https://placehold.co/12x12/e0af68/e0af68.png) `#E0AF68`, error ![#F7768E](https://placehold.co/12x12/f7768e/f7768e.png) `#F7768E`. Text tint
is pinned to ![#C7D1FD](https://placehold.co/12x12/c7d1fd/c7d1fd.png) `#C7D1FD`, a touch brighter than Tokyo Night's ![#C0CAF5](https://placehold.co/12x12/c0caf5/c0caf5.png) `#C0CAF5` so it
stays crisp on the glass.

Frosted glass is on at `frosted: Low` with an opacity table of 0.66 to 0.96,
tinted with the palette's middle neutral ![#545C7E](https://placehold.co/12x12/545c7e/545c7e.png) `#545C7E`, the same glass as every
other rice. It covers windows, panel, applets and system UI (maximized apps
stay solid), and corners are squared (`radius_*: 2.0`), the same as the
DarkGold baseline.
Adjust it on Appearance → Style → Frosted glass after import; the Import button keeps those
sliders. Export from Appearance if you tweak it so you do not
lose the changes.

**Known COSMIC bug:** moving the frosted glass opacity / thickness sliders can
reset `text_tint` to ![#FFFFFF](https://placehold.co/12x12/ffffff/ffffff.png) `#FFFFFF`. If your text turns white, re-import
`cosmic/TokyoNight.ron`; it carries the tint. Upstream fix proposed in
[libcosmic#1450](https://github.com/pop-os/libcosmic/pull/1450), not merged.

### Baseline settings

`cosmic/config/` holds the settings that make up the look and rarely change
(panel, dock, applets and shortcuts are left out on purpose):

| Where | Setting |
|-------|---------|
| Fonts | Interface `Maple Mono Normal`, monospace `Maple Mono Normal NFM` |
| Icons | Cosmic-TokyoNight-Dark |
| Windows | Minimize / maximize buttons hidden, theme applied to GNOME apps |
| Terminal | Maple Mono 15 (weights 500 / bold 800 / dim 300), 77% opacity, no header bar, Tokyo Night |

Install the [Maple fonts](https://github.com/subframe7536/maple-font/releases)
(Maple Mono Normal and Maple Mono Normal NFM) and the Cosmic-TokyoNight icons
(see Icons below) and import the terminal scheme first, then:

```bash
./cosmic/install.sh
```

It backs up each file it replaces to `*.bak` and COSMIC applies it live.

## COSMIC Terminal

The desktop `.ron` does not colour ANSI text.

1. COSMIC Terminal → **View → Color schemes…** (not Settings → Appearance)
2. Dark tab → **Import** → `cosmic-term/TokyoNight-term.ron`
3. View → Settings → Appearance → Color scheme (dark) → **Tokyo Night**

If a profile is set as default, set the scheme on that profile too or the
dropdown will look like it did nothing.

If storm grey is not the plain text you want, there are five other variants
with the same ANSI colours, from Muted ![#737AA2](https://placehold.co/12x12/737aa2/737aa2.png) `#737AA2` to
Pale ![#C4CFF4](https://placehold.co/12x12/c4cff4/c4cff4.png) `#C4CFF4`. Previews and which to
pick: [`cosmic-term/README.md`](cosmic-term/README.md).

## Firefox

Two layers:

1. **Theme (colours):** install
   **[Cosmic Night on addons.mozilla.org](https://addons.mozilla.org/en-US/firefox/addon/cosmic-night/)**.
   This is the main look: a true-black theme whose palette comes from the
   astronaut wallpaper rather than from Tokyo Night (see the second table
   under Palette). Blue chrome, a lime focus accent, red for alerts.
2. **Stylesheets (optional):** `firefox/chrome/` adds rounded corners, menu
   borders and the new tab accent on top of the theme:

```bash
./firefox/install.sh
```

Fully restart Firefox afterward: `userChrome.css` is only parsed at startup.

Full details and CSS gotchas in [`firefox/README.md`](firefox/README.md).

## Brave

`brave/theme` is a Chromium theme with the Firefox theme's colours: true-black
frame, navy toolbar, blue icons and inactive tabs, lime on the active tab.
Brave, Chrome, Chromium and Edge take it, and it loads straight from the
clone, so no Chrome Web Store or Google account is needed:

`brave://extensions` → **Developer mode** → **Load unpacked** → `brave/theme`

Leave the clone in place, Brave keeps reading the folder. Colours, limits and
packing a `.crx`: [`brave/README.md`](brave/README.md).

## Claude Desktop

For the unofficial [claude-desktop-extra](https://github.com/patrickjaja/claude-desktop-extra)
Linux build. `claude-desktop/cosmic-tokyo-night.jsonc` is one theme with both halves:
Tokyo Night in dark mode and Tokyo Day in light mode, so Claude's own
Settings → Appearance toggle switches between the two rices.
Colours come from `cosmic/*.ron`, contrast-checked (text and button text
4.5:1, accents 3:1).

```bash
./claude-desktop/install.sh
```

It copies the file into `~/.config/Claude/themes.d/`. Then press
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> in Claude Desktop and pick **cosmic-tokyo-night**.

The same file ships in [`cosmic-tokyoday-theme`](https://github.com/atraxsrc/cosmic-tokyoday-theme),
so installing from either repo gives the same theme.

## Cursor editor

`vscode/` is a colour theme extension for [Cursor](https://cursor.com) with
both halves of the pair: **Cosmic Tokyo Night** and **Cosmic Tokyo Day**. It is a plain
VS Code theme extension, so VS Code and VSCodium take it too, and the same
folder ships in cosmic-tokyoday-theme. Code is coloured the way Neovim is in
each rice; the workbench takes the desktop's window and container colours,
with the accent on the active tab, buttons and menu highlight, and the
integrated terminal uses the COSMIC Terminal scheme. Cursor builds its Agent
and chat panels from the same theme colours, so they follow along.

```bash
./vscode/install.sh
```

It packs `vscode/` into a `.vsix` and installs it with
`cursor --install-extension`; run it again after editing the theme. Then press
<kbd>Ctrl</kbd>+<kbd>K</kbd> <kbd>Ctrl</kbd>+<kbd>T</kbd> in Cursor and pick
**Cosmic Tokyo Night**. Three lines in Cursor's `settings.json` make it follow
COSMIC's Dark / Light toggle between Tokyo Night and Tokyo Day; they, the colours and
the contrast notes are in [`vscode/README.md`](vscode/README.md).

## Telegram

`telegram/cosmic-tokyonight.tdesktop-theme` is a Telegram Desktop theme: dark
navy chat list and background, storm incoming and dark-green outgoing bubbles,
blue for the accent, links, unread badges and buttons (with navy text on
them), green for online status and read ticks. Group member names use the
rice's terminal colours. Text and badge colours are contrast-checked at 4.5:1
or better, except disabled menu items.

Settings → Chat Settings → Chat wallpaper → **Choose from file** →
`telegram/cosmic-tokyonight.tdesktop-theme` → **Apply this theme**.

The colours live in `telegram/colors.tdesktop-theme`, which is plain text;
`build.sh` zips it with the chat background into the `.tdesktop-theme`. The
background is the plain window colour; to put a wallpaper behind the chat instead
(ImageMagick re-encodes it to a 2560px JPEG, Telegram caps theme files at 5 MB):

```bash
./telegram/build.sh --wallpaper backgrounds/tokyonight-anime.png
```

Built against Telegram Desktop 7.3.1. Calls, group calls, statistics charts and
premium badges keep Telegram's own colours.

Telegram has no dark / light pairing, so Tokyo Day, the light half, ships its
own theme.

## Scripts

### `update_system.sh`

nala + flatpak updater with Tokyo Night coloured output: nala package updates
(apt fallback), Flatpak updates, a Snap function that is off by default
(uncomment `update_snap` in `main`), and a runtime timer.

```bash
chmod +x scripts/update_system.sh
./scripts/update_system.sh
```

Don't run the whole script with `sudo`: `flatpak update` would then only
update system-wide installs and skip your per-user Flatpaks.

### `switch.sh`

Makes this the active rice, coming from any other `cosmic-*-theme` rice. See
[Switching rice](#switching-rice).

```bash
./scripts/switch.sh
```

### kitty, Alacritty, WezTerm, Ghostty

The COSMIC Terminal scheme for other terminals, one file each with the same
sixteen ANSI colours, text in ![#A9B1D6](https://placehold.co/12x12/a9b1d6/a9b1d6.png) `#A9B1D6`, the cursor in ![#A9B1D6](https://placehold.co/12x12/a9b1d6/a9b1d6.png) `#A9B1D6` and the
selection on ![#4E5576](https://placehold.co/12x12/4e5576/4e5576.png) `#4E5576`. Each installer copies the file next to that terminal's
config and backs up what it replaces; the one include line you add is
printed, and is in the comment at the top of each file:

```bash
./kitty/install.sh        # ~/.config/kitty/themes/TokyoNight.conf       kitty.conf:     include themes/TokyoNight.conf
./alacritty/install.sh    # ~/.config/alacritty/themes/tokyonight.toml   alacritty.toml: [general] import = ["~/.config/alacritty/themes/tokyonight.toml"]
./wezterm/install.sh      # ~/.config/wezterm/tokyonight.lua             wezterm.lua:    config.colors = require("tokyonight")
./ghostty/install.sh      # ~/.config/ghostty/themes/TokyoNight          config:         theme = TokyoNight
```

Ghostty and WezTerm can follow COSMIC's Dark / Light toggle once the Tokyo Day
half is installed from its repo as well: `theme = dark:TokyoNight,light:TokyoDay` in
Ghostty, and in WezTerm

```lua
local dark = (wezterm.gui and wezterm.gui.get_appearance() or "Dark"):find("Dark")
config.colors = require(dark and "tokyonight" or "tokyoday")
```

kitty and Alacritty have no such switch; include the other file instead.

## Switching rice

The installers replace what they own (with a `*.bak` copy), but some things
pile up instead: shell layers in `~/.zshrc`, LazyVim specs, the updater link and
btop's theme setting. `scripts/switch.sh` makes Tokyo Night the active rice, coming
from any other `cosmic-*-theme` rice, and tidies those up. Every rice repo ships
the same script.

```bash
./scripts/switch.sh               # switch, icons included
./scripts/switch.sh --keep-icons  # leave the current icon theme alone
```

It backs up every file it replaces, then:

- copies `cosmic/config/` (fonts, terminal look, icons) and turns dark mode on.
  The terminal scheme and icon theme are only replaced when the current one is
  not already a Tokyo Night variant, so a dimmer text variant or another icon colour
  survives. Icons stay as they are until `./icons/install.sh` has run.
- runs the fastfetch, lsd, bat, starship, delta, lazygit, kitty, Alacritty,
  WezTerm, Ghostty, Helix, GTK, Qt, Discord, Neovim and Claude Desktop
  installers and sets btop's `color_theme`. The terminal, editor and Qt
  installers only copy theme files; the include line you added once stays,
  switch it by hand when the file name differs between rices
- moves every other rice's LazyVim spec from `~/.config/nvim/lua/plugins/` to
  `~/.config/nvim/rice-off/` (LazyVim loads every spec there and the last
  colorscheme wins); your own specs stay
- comments out every other rice's `source` line in `~/.zshrc`, and
  cosmic-ricing's `ricing/zsh/colors.zsh`, then uncomments Tokyo Night's or adds it
- points `~/update_system.sh` at this repo's updater
- installs the Firefox userChrome / userContent

The GUI steps it cannot do are printed at the end:

1. Settings → Desktop → Appearance → Dark → Import `cosmic/TokyoNight.ron`
2. COSMIC Terminal → View → Color schemes → Dark tab → Import `cosmic-term/TokyoNight-term.ron`
3. Firefox: disable the old rice's add-on, enable [this one](https://addons.mozilla.org/en-US/firefox/addon/cosmic-night/), restart Firefox
4. Settings → Wallpaper → a file from `backgrounds/`
5. Claude Desktop: Ctrl+Shift+T → `cosmic-tokyo-night`, Appearance → Dark
6. `exec zsh`, restart Neovim (`:Lazy clean` drops plugins only the old specs used)
7. Obsidian: `./obsidian/install.sh <vault>`; delta: the `[include]` path in `~/.gitconfig`

Skip 1 and 2 when that slot already holds Tokyo Night. The first time on this rice,
run [Setup](#setup) once for the fonts, icons and cursor.

**Within the pair** (Tokyo Night ↔ [Tokyo Day](https://github.com/atraxsrc/cosmic-tokyoday-theme)): the two halves
sit side by side in COSMIC's Dark and Light slots and share one Claude Desktop
theme, so after the first time only the Firefox add-on and the wallpaper are
left by hand. Add `--keep-icons` to keep one icon colour across the pair.

Leaving Tokyo Night is the next rice's `./scripts/switch.sh`. `./cursors/uninstall.sh`
puts the Pop cursor back.
